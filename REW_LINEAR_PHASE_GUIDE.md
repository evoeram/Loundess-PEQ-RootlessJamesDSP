# Измерение Linear Phase GEQ в REW — инструкция
# (актуально и для Linear Phase PEQ, начиная с модуля v6.3.20)

Проверено для JamesDSP v1.6.27 (code 70) + модуль v6.3.18-peq-loudness.
Линейная фаза в этом DSP — фильтр с конечной импульсной характеристикой на 16383 отсчёта,
с центром на отсчёте 8191. Это и есть ключ к измерению.

## 1. Что измеряем

Сравниваем два состояния одной и той же GEQ-кривой:

- `geq_linear_phase = false` (minimum phase) — задержки нет, импульс несимметричный.
- `geq_linear_phase = true` (linear phase) — появляется чистая задержка **8191 отсчёта**
  и импульс становится симметричным относительно пика.

## 2. Схема подключения

```
ПК (REW) → внешняя карта, выход → телефон (вход, JamesDSP в тракте) → внешняя карта, вход → ПК (REW)
```

- В JamesDSP включён только GEQ с тестовой кривой, например:
  `GraphicEQ: 100 0.0; 1000 3.0; 10000 0.0;`
- Всё остальное (Bass Boost, Loudness, Live Programs, Stereo Wide и т.д.) — выключено.
- Формат потока: 48 кГц. Проверить: `dumpsys media.audio_flinger` — у эффекта JamesDSP
  должно быть `48 kHz`. При другой частоте задержка пересчитывается: `8191 / частоту`.
- Громкость телефона фиксированная, без нормализации громкости в цепи.

## 3. Настройки REW

- Preferences → Soundcard: выбрать внешнюю карту, калибровку не трогаем (измеряем относительные вещи).
- Измерение: sweep 15–20000 Гц, уровень −12 dBFS (без клипа по всей цепи).
- **Acoustic timing reference — не обязателен**, задержку определяем по импульсу (шаг 5).

## 4. Порядок измерения

1. Переключить `geq_linear_phase = false` → измерение A (minimum phase).
2. Не меняя ничего в тракте, переключить `geq_linear_phase = true` → измерение B (linear phase).
3. Важно: между измерениями не трогать громкость и не переподключать кабели —
   иначе сравнение уровней потеряет смысл.

## 5. Анализ: задержка

У измерения B откройте **Impulse response**:

- Ожидаемый пик на **8191 отсчёта ≈ 170,85 мс** при 48 кГц (минус небольшой
  собственный latency тракта — определяется по измерению A или по bypass).
- В REW: Impulse → **Estimate IR delay** — REW покажет найденную задержку и может
  сдвинуть IR так, чтобы пик оказался на t=0.
- Если пик на ~0 мс — линейная фаза НЕ работает (кривая применилась как minimum phase).
  Это ровно симптом старого бага, который исправлен в v6.3.18.

## 6. Анализ: симметрия импульса

После компенсации задержки (пик на t=0):

- Linear phase: импульс **симметричен** относительно пика — левое и правое крыло зеркальны.
- Minimum phase: импульс сильно **несимметричен** — энергия вся в начале.

## 7. Анализ: АЧХ

Сравните SPL измерений A и B (с учётом сдвига задержки у B):

- Обе кривые должны практически совпадать (в нативном тесте расхождение ≤ 0,0052 dB).
- Если АЧХ совпадает, но импульс симметричен и задержан — **Linear Phase работает**.
- Если АЧХ не совпадает или проваливается у краёв диапазона — смотрим формат потока
  (должен быть 48 кГц float) и клип по уровню.

## 8. Типичные ловушки

| Симптом | Причина |
|---|---|
| Пик на ~0 мс при linear | Переключение фазы не дошло до DSP (старая библиотека/не root) |
| Задержка есть, но АЧХ «рваная» | Клип в тракте, поднять порог sweep |
| Разная задержка между записями | Переподключение/перезапуск аудиотракта, вариативная latency |
| Импульс симметричен, но пик не на 8191 | Частота не 48 кГц — пересчитать `8191/Fs` |

## Контрольные числа (нативный тест на самом устройстве)

- minimum phase: 8192 taps
- linear phase: 16383 taps, центр на отсчёте 8191
- симметрия: коэффициент 0,0000
- расхождение АЧХ min vs linear: ≤ 0,0052 dB

## 9. Linear Phase PEQ (модуль v6.3.20+, приложение v1.6.29-73+)

PEQ получил собственный режим линейной фазы (переключатель «Linear phase» в
настройках PEQ). Ядро — то же, что у GEQ: нечётный симметричный КИФ на
16383 тапа с центром на отсчёте 8191 (задержка 8191/Fs ≈ 170,7 мс @ 48 кГц),
поэтому вся методика измерения выше применима один в один:

- В JamesDSP включён только PEQ с одним peaking-бэндом (например 1000 Hz, +6 dB, Q 1.4).
- `peq_linear_phase = false` → импульс несимметричный, пик около t=0.
- `peq_linear_phase = true` → пик на 8191 отсчёте, крылья зеркальны.

Нативный тест (arm64, изолированный харнесс debug/fir_test) подтверждает:
длина 16383, пик 8191, симметрия 0,000001, DTFT ядра +6,0000 dB @ 1 kHz,
сквозное усиление через FFT-конволвер +6,0016 dB.

Отличие от GEQ: PEQ строит ядро аналитически — спектр каскада биквадов
выборка за выборкой на сетке 16384 точек (включая маршрутизацию L/R и
преамп), без лог-сеточной интерполяции узлов. Банды cutoff-фильтров
учитываются как полный Баттерворт-каскад. Latency-компенсации нет —
задержка неотъемлема для линейной фазы.
